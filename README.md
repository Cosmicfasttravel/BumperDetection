# Bumper Detection

The goal of this project is to detect robot bumpers and estimate the position and team number of each robot within the camera's field of view.

---

# Branch Information
## **Main**
- This branch is for information purposes

## **OrangePi5**
- This branch is for development on the Orange PI 5 RK3588, this branch will **NOT** work with any other devices including other Orange Pis without the RK3588 processor
- This branch **may** have issues but is ***more stable*** than the **GPU** branch and has more features

## **opi5-v2**
- This branch **requires OrangePi5**
- Currently this branch is **NOT** ready for deployment or any usage as it is in heavy development

## **GPU**
- This branch **requires NVIDIA GPU**
- Currently this branch is **NOT** ready for deployment or any usage and is far behind in features
